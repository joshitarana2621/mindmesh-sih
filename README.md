# Eduadpat

Architecture-first scaffold for the Offline-First Blended Learning Platform.

## Current contents

- `docs/architecture/` contains the six completed architecture pages.
- `apps/`, `packages/`, and `tests/` provide the approved project layout.

## Important

This folder currently contains the project structure and architecture documentation only. Application source code, dependencies, database configuration, and authentication are not implemented yet.

Before implementation begins, confirm the required software and accounts listed in the architecture documentation.
